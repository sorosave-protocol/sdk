# Sorosave SDK Documentation

Welcome to Sorosave SDK documentation.

## Quick Start

```bash
npm install @sorosave/sdk
```

## Usage

```javascript
import { Sorosave } from '@sorosave/sdk';

const client = new Sorosave({
  network: 'mainnet'
});
```

## Features

- Decentralized savings pools
- Governance participation
- Transparent on-chain transactions
